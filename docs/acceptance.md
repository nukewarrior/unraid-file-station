# v0.1 人工验收清单

目标环境：Unraid **7.2.2**，现代 Chromium 浏览器，Tampermonkey，macOS 与 Windows 至少各一次。

> 当前尚未完成真实设备上的验收；下方是待执行的检查流程，不代表已经通过。

## v0.1.6 DSM 选择与固定工具栏验收（当前版本优先）

> 旧版本的“选中后出现上下文工具栏”验收项已被本版本废弃，请优先按本节检查。

- [ ] 不选中任何文件时，右侧只有固定的路径栏与文件操作栏。
- [ ] 单击任意文件或文件夹，**只改变该行浅蓝色选中背景**，工具栏数量、按钮位置、文件列表顶部坐标不变化。
- [ ] 左侧目录树当前目录仍以橙色突出显示，不受右侧文件选择高亮影响。
- [ ] Ctrl/⌘ + 点击增加或取消选中，Shift + 点击连续范围选择，重复操作不让文件区域跳动。
- [ ] Ctrl/⌘ + A 可以全选；Esc、点击文件列表空白处可以清空选择。
- [ ] 右键点击已选中的文件可以保持多选；右键未选中的文件时改为选中该文件。
- [ ] 在多选状态右键菜单不错误提供仅适用一个文件的下载/打开动作。
- [ ] 双击文件夹能够进入文件夹，原有面包屑导航和目录树状态正确。
- [ ] 固定「操作」菜单包含可用的复制路径、属性、单文件下载（仅选中一个普通文件）、原生回退。
- [ ] 底部状态栏显示选中项目数；若选中的是已知大小的普通文件，显示正确合计；文件夹大小不伪造。
- [ ] 在列表/网格视图中选择文件后，页面高度、滚动与右侧详情面板均正常。
- [ ] 未启用新建/上传/移动/删除等写入操作；返回原生管理器功能正常。
- [ ] Unraid 完整头部和折叠头部下均不出现曾修复过的无限滚动。

- [ ] 不按 Shift 普通单击和双击仍正常；Ctrl/⌘ 多选与 Shift 组合保持范围行为。
- [ ] 右键文件仍可唤起右键菜单，不被 mousedown 拦截。
- [ ] 鼠标悬停左侧共享文件夹名称（如 appdata、downloads）时是正常箭头，不是 I 形文本光标。
- [ ] 左侧目录树的展开箭头与文件夹点击均正常工作；右侧文件高亮不影响左侧当前目录。
- [ ] 筛选输入框仍可输入和选择文字，文件列表的滚动、高度、操作菜单保持不变。

## v0.1.8 OWNER 与 LOCATION 列专项验收

- [ ] 宽窗口列表显示「名称、大小、修改日期、OWNER、权限、LOCATION」六列，表头与行内容一一对齐，不截断文件名或其他列。
- [ ] OWNER 与原生 Unraid Browse 页面一致，分别验证 nobody、root 等所有者。
- [ ] LOCATION 与原生 Browse 页面一致，分别验证单磁盘、多个磁盘、缓存池、空值/未知位置。
- [ ] LOCATION 不出现「Not encrypted」「Locked」「Encrypted and unlocked」等加密状态提示文本。
- [ ] 同一位置不会重复；v0.1.9 起连续磁盘压缩为区间，点击可查看完整设备列表（不再使用 +N）。
- [ ] LOCATION 空值应显示 —，不根据逻辑路径猜测 disk1 或 cache。
- [ ] OWNER、LOCATION 列标题都能切换升降序；文件夹仍在文件之前。
- [ ] 打开单个文件的属性面板，能看到所有者、存储位置及逻辑路径三个独立字段。
- [ ] 网格视图不显示挤在图标下的详细属性；返回列表后信息仍正确。
- [ ] 浏览器宽度 1920px、1366px、1200px、980px、720px 时没有列错位或横向溢出，窄屏自动隐藏低优先级列。
- [ ] Shift/Ctrl/⌘ 选择、右键操作、双击导航、内部滚动和原生回退仍然正常。
- [ ] 不新增 NAS 文件写入操作、数据库或其他服务端请求。

## v0.1.9 三处 UI 修复专项验收（当前版本优先）

- [ ] 鼠标点击「详细信息」打开，再点击关闭，按钮不残留橙色/黄色边框；按 Tab 聚焦时仍看得见焦点轮廓。
- [ ] LOCATION 有 disk2、disk3、disk4 时显示 `disk2–disk4` 而不是 `disk2 disk3 +1`。
- [ ] LOCATION 存在 disk1、disk3、disk5 时不会误写成连续区间；非磁盘设备如 cache 保留。
- [ ] 点击 LOCATION 摘要可弹出所有实际设备；点击空白处、按 Esc 或按关闭按钮可以关闭弹层。
- [ ] 点击 LOCATION 不触发文件行选择，双击 LOCATION 不会进入所在文件夹。
- [ ] 对十几/几十块磁盘，摘要不会撑大表格行，弹层内容可独立滚动，并可查看全部磁盘名称。
- [ ] 不会显示 `+N` 代替丢失的磁盘细节，未知位置仍显示 `—`。
- [ ] 名称、大小、修改日期、OWNER、权限、LOCATION 六个表头在垂直方向居中，排序箭头与文字对齐。
- [ ] 点击表头仍可排序、文件列表与目录树照常滚动；顶部、底部布局不改变。
- [ ] 两种主题、正常/收缩 Unraid 顶栏、1366px / 1920px 宽度下，没有弹层溢出或横向布局错位。
