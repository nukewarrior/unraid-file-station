# v0.1 人工验收清单

目标环境：Unraid **7.2.2**，现代 Chromium 浏览器，Tampermonkey，macOS 与 Windows 至少各一次。

> 当前尚未完成真实设备上的验收；下方是待执行的检查流程，不代表已经通过。

## 安装和回退

- [ ] 在 SHARES > User Shares 区域出现 FILE STATION 按钮。
- [ ] 点击共享名称仍进入 Unraid 原生共享设置，不被脚本劫持。
- [ ] 点击共享名称左侧蓝色 Browse 图标，自动打开对应共享，例如 /mnt/user/downloads。
- [ ] 顶部 Dashboard、Main、Shares、Docker 等原生导航未变化。
- [ ] 点击“返回原生”后，刷新并恢复原生 Browse 表格及按钮。
- [ ] 点击“打开 File Station”后可重新进入增强界面。
- [ ] 禁用/卸载脚本后可以正常使用所有原生页面。

## 文件导航

- [ ] 左侧所有共享与 NAS 上真实 /mnt/user 内容一致。
- [ ] 双击文件夹进入、点击目录树切换、面包屑上行。
- [ ] 在多个目录创建标签页并切换；关闭标签不会丢失其他标签。
- [ ] 后退/前进以及浏览器返回可回到正确目录。
- [ ] 刷新后文件列表与文件夹内容一致。
- [ ] 空文件夹、权限不足、未挂载目录、HTTP 失败有明确状态。
- [ ] 含中文、空格、引号、&、#、? 的文件名完整显示。
- [ ] 包含大量文件的目录仍可操作；记录刷新时间与滚动表现。

## 交互

- [ ] 列表/网格视图切换、重新打开后保持用户选择。
- [ ] 当前目录过滤不会影响真实 NAS 文件。
- [ ] Ctrl/⌘ 多选、Shift 范围选、Ctrl/⌘+A、Escape 行为正确。
- [ ] 右键菜单不会溢出浏览器视口。
- [ ] 右键选中项目、复制完整路径、下载单个文件。
- [ ] 详细信息侧栏正确显示文件大小、修改时间、权限、所有者。
- [ ] Unraid 与 DSM 两种主题在刷新后保留；与现有 WebGUI 黑色主题相容。
- [ ] 1366px、1920px、移动窄屏下无严重重叠和丢失操作入口。

## 安全验证

- [ ] 打开脚本期间，未触发 Control.php 的文件写入动作。
- [ ] 不允许从 /mnt/user 导航至 /mnt/disk1 或 /boot。
- [ ] 不会通过前端自动修改 NAS 的文件时间戳、权限或所有者。
- [ ] 删除、复制、上传、重命名按钮在 v0.1 不执行文件写入。
- [ ] 所有网络请求均为同源 Unraid 请求，不依赖第三方 API。
- [ ] Script 关闭后，原生文件管理器的工作完全不受影响。

## 后续写入能力引入前必须重新验收

- [ ] 确认 Unraid 7.2.2 Control.php 与其任务队列的真实行为。
- [ ] 检查路径 realpath、符号链接与目录穿越处理。
- [ ] 确认 /mnt/user 与 /mnt/disk* 的混用防护。
- [ ] 覆盖、跳过、重命名冲突策略与原生接口实际一致。
- [ ] 大文件、多文件并发、异常中断、重复执行和浏览器刷新不会损坏文件。
- [ ] 用户明确确认后，才开放删除、移动和覆盖操作。
