# v0.1 人工验收清单

目标环境：Unraid **7.2.2**，现代 Chromium 浏览器，Tampermonkey，macOS 与 Windows 至少各一次。

## v0.2.3.14 工具栏新建文件夹直达验收

- [ ] 顶部「文件」区域原先的「+ 新建 ▾」变为文字按钮「新建文件夹」，不显示加号和下拉箭头，原有「操作 ▾」样式及功能保持不变。
- [ ] 鼠标直接点击「新建文件夹」立即打开原新建文件夹弹窗，不再先出现只有一个「新建文件夹」选项的下拉菜单。
- [ ] 使用键盘 Tab 定位该按钮后按 Enter/空格也直接打开弹窗；输入框默认名称与选中文字、Esc/取消关闭行为正常。
- [ ] 在某个真实 Share 和子目录中新建测试文件夹，仅一次创建请求；同名名称拒绝、非法名称校验与正在执行其他原生写入任务时拒绝提交的规则不变。
- [ ] 已打开「操作 ▾」时再点击「新建文件夹」，旧菜单关闭且只出现一个创建弹窗，不遗留遮挡层或菜单。
- [ ] 复制弹窗内的行内新建、重命名、复制、滚动条、52px 标题区和 64px 底部按钮区不受影响；不产生任何额外复制/删除/移动操作。


## v0.2.3.13 复制弹窗 Esc 和焦点专项验收

- [ ] 从文件右键菜单打开「复制到」，不再点击窗口内任何位置，立即按 Esc 即关闭；原文件仍选中，未发送文件写入。
- [ ] 选择目标目录后 Esc 正常关闭；再次打开目录树、展开/收起、切换选择后 Esc 同样有效，关闭时尽量回到原操作位置。
- [ ] 在复制目标树中新建文件夹，编辑输入框时第一次 Esc 仅取消行内编辑，复制窗口保留；第二次 Esc 关闭窗口，不创建文件夹。
- [ ] 复制进行中按 Esc 仅收起到后台，原生复制继续；点击「复制任务进行中」重新打开后，Esc 仍能再次收起，不发送任何 `action=99`。
- [ ] 复制成功后按 Esc 可关闭完成结果，结果不确定时按 Esc 可关闭提示，但不会自动重试、取消或清理目标。
- [ ] 新建文件夹和重命名弹窗的默认输入焦点、Esc 关闭行为不回归；复制取消仍需要点击「取消复制」并经过原生二次确认。
- [ ] 三种弹窗 v0.2.3.12 实机已验收的标题高度、底部按钮、颜色、图标和滚动条继续保持不变。


## v0.2.3.12 统一 File Station 弹窗规范专项验收

- [ ] 在正常窗口中分别打开「新建文件夹」「重命名」「复制到」，所有标题栏约 52px、底部按钮栏约 64px，标题与关闭按钮垂直居中，操作按钮按原顺序对齐。
- [ ] 普通短内容的创建/重命名弹窗高度自然收缩，无大片空白或多余滚动条；长父路径/文件名和约 480px 低窗口下，正文单独滚动，标题和按钮完整留在可视区域。
- [ ] 复制目标树与外层正文滚动条初始透明，悬停、滚动时显示 6px 细滑块；移出并停止滚动约 1.1 秒后隐藏，鼠标拖动滚动条和触控板操作正常。
- [ ] 鼠标悬停复制目标目录树时仅内层滚动条高亮，外层不同时显现。目录树懒加载、排序、行内新建、选中目录及现有滚轮行为均不受影响。
- [ ] 复制的准备、进度、后台、完成、取消状态下按钮栏固定；成功完成仍由用户手动关闭，取消复制仍调用原生确认框并保留任务归属检查。
- [ ] 创建、重命名正常提交仍只发出预期的原生写入请求；短/长中文或英文名称不会引入横向滚动、表单提交重复、焦点丢失。
- [ ] 本版不修改原生确认框、不开发上传/移动/删除，不改变 Unraid 原生 WebGUI 的顶部底部、目录树文件列表样式。
