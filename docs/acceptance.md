# v0.1 人工验收清单

目标环境：Unraid **7.2.2**，现代 Chromium 浏览器，Tampermonkey，macOS 与 Windows 至少各一次。

> 当前尚未完成真实设备上的验收；下方是待执行的检查流程，不代表已经通过。

## 安装和回退

- [ ] 在 SHARES > User Shares 区域出现 FILE STATION 按钮。
- [ ] 点击共享名称仍进入 Unraid 原生共享设置，不被脚本劫持。
- [ ] 点击共享名称左侧蓝色 Browse 图标，自动打开对应共享，例如 /mnt/user/downloads。
- [ ] 顶部 Dashboard、Main、Shares、Docker 等原生导航未变化。
- [ ] 点击“返回原生”后，刷新并恢复原生 Browse 表格及按钮。
- [ ] 点击“打开 File Station”后可重新进入增强界面。
- [ ] 禁用/卸载脚本后可以正常使用所有原生页面。

## 根据 Unraid 7.2.2 实机截图补充的 UI 验收

- [ ] **展开顶部主标题时**（LOGO、Uptime 可见），File Station 底部状态栏不被 Unraid `#footer` 遮挡；没有第二套原生面包屑和 `file type` 输入框。
- [ ] **折叠顶部主标题时**（仅保留顶部导航菜单），File Station 自动延伸至 `#footer` 上方，不留下大块灰色空白。
- [ ] 切换头部展开/折叠无需刷新，File Station 高度能自动重算。
- [ ] 浏览器页面默认不出现不必要的外部滚动条；文件列表内部滚动且标题仍可见。
- [ ] 目录树的 16px 展开箭头、文件夹图标、名称靠近并对齐，不出现按钮被 Unraid 全局样式拉宽的问题。
- [ ] 目录树分隔线拖动调宽，刷新后记住宽度；窄屏会自动收起文字。
- [ ] 文件夹名称保留真实大小写，包括 `downloads`，标签页不被强制转换为 `DOWNLOADS`。
- [ ] 目录树长路径显示省略号并可通过 title 查看完整路径。
- [ ] 列表/网格切换按钮使用浅色高亮，而不是大块橙色主操作按钮。
- [ ] 文件图标显示一致，文件夹/压缩包/图片/视频使用内置 SVG，没有平台不同的 Emoji 图标。
- [ ] 点击列头后名称、大小、修改时间等排序正确；文件夹始终排列在文件前面。
- [ ] 尚未接入的写入按钮均显示禁用，鼠标不会执行写入操作。
- [ ] 点击“返回原生”，原生 Browse 文件表格、原生路径栏、过滤器完整恢复。
- [ ] Unraid 黑色主题与 DSM 蓝白主题都无图标溢出、字体对齐或外部 CSS 污染。
- [ ] 浏览器缩放 80% / 100% / 125% 与窗口 1366px / 1920px 下无异常。

## v0.1.2 无限滚动专项回归

- [ ] 先刷新进入 `/Shares/Browse?dir=/mnt/user/downloads`，确保浏览器右侧外层页面没有可无限向下滚动的区域。
- [ ] 在文件列表里连续向下滚动 20 次，File Station 容器高度保持不变，顶部工具栏和底部状态栏不会消失。
- [ ] 在左侧目录树里滚动，只有目录树内容变化，不带动整个浏览器文档移动。
- [ ] 鼠标放在标签栏、工具栏等不可滚动区域滚轮向下，浏览器页面不发生整体偏移。
- [ ] 在 Unraid 头部展开和折叠两种状态下重新测试；布局能填满底部状态栏上方的空间。
- [ ] 通过「返回原生」切换后，原生 Browse 允许正常滚动，没有残留增强版的 `overflow-y:hidden`。
- [ ] 刷新多次、通过浏览器后退/前进进入 Browse 后，不会留下异常滚动偏移。
- [ ] 关闭或卸载 Tampermonkey 脚本后，不影响 SHARES、MAIN 等原生页面的滚动。

## v0.1.3 工具栏与悬浮控件专项验收

- [ ] File Station 工具栏右侧不再出现短条状的竖向滚动条。
- [ ] 在 100%、125% 浏览器缩放及窄窗口下，工具栏按钮均可通过横向滚动访问，但不出现竖向滚动条。
- [ ] File Station 右下角不再出现 Unraid 原生红色「回到页首」「移至页尾」箭头。
- [ ] 文件列表、左侧目录树仍能各自滚动，不影响之前已修复的外层页面无限滚动问题。
- [ ] 通过「返回原生」切换到 Unraid Browse 后，原生页面的滚动控件不被永久隐藏。
- [ ] 回到 SHARES / MAIN 等原生页面时，Unraid 的全局滚动按钮仍按默认行为显示。
- [ ] Unraid 顶部展开和折叠两种状态均无视觉回归。

## v0.1.4 双行顶部和上下文操作栏验收

- [ ] 默认只有两条常驻顶部行，标题与标签页在同一行，导航与视图切换在另一行。
- [ ] File Station 标题、目录标签、右侧刷新和更多按钮在宽屏下对齐且没有溢出。
- [ ] 点击加号可以打开新标签；切换与关闭标签后当前目录和选择状态正常。
- [ ] 更多菜单包含返回原生管理器、主题切换和关于；重复点击更多图标可关闭菜单，点击外部也可关闭。
- [ ] 当前目录筛选默认不显示输入框；点击搜索图标显示并聚焦；关闭输入框后清空过滤，恢复全部文件。
- [ ] 列表、网格与详情视图仍可正常切换，面包屑在长路径下优先展示当前目录。
- [ ] 未选中文件时上下文操作栏隐藏；选中一项或多项后出现，并显示正确项目数量。
- [ ] 选中单个普通文件可以显示下载；选中目录或多个项目时下载按钮隐藏。
- [ ] 复制路径仅复制选中项目路径，点击属性打开详情栏，取消选择恢复双行顶部。
- [ ] v0.1.4 没有可点击的灰色写入工具栏，创建、上传、移动和删除继续由 Unraid 原生页面执行。
- [ ] 在头部完整展开/折叠状态下，File Station 高度仍正确，外层页面不出现无限滚动。
- [ ] 切换回原生 Browse 后保持当前目录，原生顶部、工具栏和文件管理操作正常。
- [ ] 1366px / 1920px 及窄窗口下，导航图标、标签页和可展开搜索不会遮挡彼此。

## 文件导航

- [ ] 左侧所有共享与 NAS 上真实 /mnt/user 内容一致。
- [ ] 双击文件夹进入、点击目录树切换、面包屑上行。
- [ ] 在多个目录创建标签页并切换；关闭标签不会丢失其他标签。
- [ ] 后退/前进以及浏览器返回可回到正确目录。
- [ ] 刷新后文件列表与文件夹内容一致。
- [ ] 空文件夹、权限不足、未挂载目录、HTTP 失败有明确状态。
- [ ] 含中文、空格、引号、&、#、? 的文件名完整显示。
- [ ] 包含大量文件的目录仍可操作；记录刷新时间与滚动表现。

## 交互

- [ ] 列表/网格视图切换、重新打开后保持用户选择。
- [ ] 当前目录过滤不会影响真实 NAS 文件。
- [ ] Ctrl/⌘ 多选、Shift 范围选、Ctrl/⌘+A、Escape 行为正确。
- [ ] 右键菜单不会溢出浏览器视口。
- [ ] 右键选中项目、复制完整路径、下载单个文件。
- [ ] 详细信息侧栏正确显示文件大小、修改时间、权限、所有者。
- [ ] Unraid 与 DSM 两种主题在刷新后保留；与现有 WebGUI 黑色主题相容。
- [ ] 1366px、1920px、移动窄屏下无严重重叠和丢失操作入口。

## 安全验证

- [ ] 打开脚本期间，未触发 Control.php 的文件写入动作。
- [ ] 不允许从 /mnt/user 导航至 /mnt/disk1 或 /boot。
- [ ] 不会通过前端自动修改 NAS 的文件时间戳、权限或所有者。
- [ ] 删除、复制、上传、重命名按钮在 v0.1 不执行文件写入。
- [ ] 所有网络请求均为同源 Unraid 请求，不依赖第三方 API。
- [ ] Script 关闭后，原生文件管理器的工作完全不受影响。

## 后续写入能力引入前必须重新验收

- [ ] 确认 Unraid 7.2.2 Control.php 与其任务队列的真实行为。
- [ ] 检查路径 realpath、符号链接与目录穿越处理。
- [ ] 确认 /mnt/user 与 /mnt/disk* 的混用防护。
- [ ] 覆盖、跳过、重命名冲突策略与原生接口实际一致。
- [ ] 大文件、多文件并发、异常中断、重复执行和浏览器刷新不会损坏文件。
- [ ] 用户明确确认后，才开放删除、移动和覆盖操作。
