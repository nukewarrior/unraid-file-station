# File Station 弹出界面设计规范

本规范适用于修改现有功能和新增功能时涉及的对话框、任务面板、位置浮层、菜单、确认框及短暂提示。目标是复用已验收的视觉基线，保持关闭、提交、后台运行和停止任务的含义一致。

本文基于当前源码、既有验收记录和回归测试整理。“必须”是后续开发约束，不代表当前全部窗口已经满足。现有差异列在第 8 节；本次仅建立规范，不修改运行时界面。

## 1. 使用与维护

- 修改弹出界面前必须阅读本文，确认所属类型、影响的入口及任务状态。工具栏、右键、快捷键和后台恢复应进入同一实现，不另写布局或提交逻辑。
- 新增同类窗口必须复用现有样式、原生 API、校验和任务机制；专有类只扩展业务内容，不重新定义通用外框。保留单文件 UserScript，不为弹窗引入生产依赖。
- 新功能遵守全部相关规则；修改既有功能时，变更涉及的界面和交互应遵守规范。未涉及的历史差异不顺手重构，也不能复制为新功能的默认模式。
- 确需不同尺寸或交互时，先在本文记录适用场景、原因和验收项，再实现。差异不能取消安全校验、结果核验、键盘操作和固定操作区。
- 调整共用规则时检查所有使用者、相关测试和验收项，避免只修改一个窗口造成分叉。用户明确要求和更严格的项目安全规则优先。
- README 版本记录保留历史含义，后续设计以本文为准。早期复制成功自动关闭、刷新丢失内存队列等记录，不作为当前实现依据。

## 2. 当前入口与类型

### 2.1 自定义弹出界面

| 类型 | 触发操作 | 当前实现 | 内容与用途 |
| --- | --- | --- | --- |
| 操作对话框 | 工具栏“新建文件夹” | `showCreateFolderDialog()` | 当前位置、名称输入、创建状态；一次点击直达 |
| 操作对话框 | 单选后从操作/右键菜单重命名，或 F2 | `showRenameDialog()` | 原名称、新名称、提交状态 |
| 操作对话框 | 单选/多选后从操作/右键菜单选择“复制到…” | `showCopyDialog()` | 已选摘要、目标树、同名策略、预检、进度和结果 |
| 操作对话框 | 在任务中心点击本页面创建的任务 | 任务的 `reopen()` | 恢复同一复制窗口，不新建任务 |
| 任务详情对话框 | 在任务中心点击持久化恢复的任务 | `showRecoveredCopyDetails()` | 已保存项目状态、目标和策略、人工核实并跳过入口 |
| 诊断对话框 | 顶部诊断图标、更多菜单、原生模式诊断按钮 | `showDiagnosticCenter()` | 日志、增强诊断、标记、导出、清空；当前独立外框 |
| 任务浮动面板 | 点击底部状态栏右侧任务按钮 | `showCopyTaskCenter()` | 运行、等待、完成、失败、待核实任务及队列恢复 |
| 位置浮层 | 点击存储位置/“查看全部” | `showLocationPopover()` | 完整设备列表、复制位置 |
| 菜单 | “操作”、更多、右键、面包屑省略号 | `showFileActionMenu()`、`showAppMenu()`、`showBreadcrumbMenu()` | 动作或导航入口，不承载长表单 |
| 短暂提示 | 复制路径、操作成功、关于、功能未接入等 | `notify()` | 右下角提示，当前约 3500ms 后移除 |

复制目标树的新建目录是行内编辑；批量“查看全部”是原窗口中的清单视图，均不叠加独立对话框。“属性”使用右侧详情栏，“在新标签页中打开”使用 File Station 内部目录标签页，均不属于新浏览器窗口。

### 2.2 浏览器原生确认

当前六处 `window.confirm()`：停止单项复制、批量尝试停止当前项及后续队列、恢复尚未执行的持久化队列、核实异常后继续排队、人工核实并跳过恢复项目、清空诊断日志。

存在运行中或待核实任务时，刷新/关闭/离开页面通过 `beforeunload` 请求离开确认。浏览器可能不显示，不能依赖它保证任务安全。

保留上述确认的触发时机和安全含义。输入、目标选择、长列表使用自定义对话框，不用 `prompt()` / `alert()`。新的停止、破坏性操作或人工恢复流程如需二次确认，应说明对象、后果和继续条件；普通打开、关闭和只读查看不增加确认。原生确认框视觉由浏览器控制，迁移为自定义确认框需单独设计和验收。

## 3. 类型选择与层级

- 操作对话框用于输入、目标选择和操作过程，以当前 File Station 区域为遮罩范围，居中显示，背景不能继续触发文件操作。
- 任务面板/位置浮层用于快速查看，锚定任务按钮或位置单元格，无全屏遮罩；长操作通过入口进入对应对话框。
- 菜单贴近触发点，超出视口时调整位置；同一时间只保留一个菜单或位置浮层。短暂提示只作轻量反馈，需要修正、核实或保留的错误/结果必须留在相关窗口或任务记录中。
- 打开对话框前关闭临时菜单和浮动面板。新增/调整模态入口必须防止多个模态窗口叠放，检查范围包含独立挂在 `document.body` 的诊断窗口。
- 查看任务时重新挂载原窗口或展示保存详情，不能再次提交。行内编辑和任务清单在父窗口内切换，不套多层模态框；浏览器二次确认是现有受控例外。
- CSS 限定在 `#ufs-app` 或专用 `ufs-` 容器，沿用既有层级，不影响 Unraid 全局按钮、页面滚动、顶部导航和底部状态栏。

## 4. 操作对话框视觉基线

新建、重命名、复制及恢复任务详情使用共用外框。任务面板、位置浮层不强制使用相同宽度和标题/底栏高度。

### 4.1 结构与尺寸

复用 `.ufs-dialog-overlay`、`.ufs-create-dialog`、`.ufs-create-head`、`.ufs-create-form`、`.ufs-create-fields`、`.ufs-create-buttons`；无表单详情可省略 `form`，保留标题、滚动正文和固定底栏。复制通过 `.ufs-copy-dialog` 扩展内容。

| 项目 | 统一基线 |
| --- | --- |
| 宽度 | 默认 `min(440px, 100%)`；复制及恢复复制详情 `min(465px, 100%)` |
| 高度 | 短内容自然收缩；外框 `max-height: calc(100% - 16px)`、`min-height: 0`、`overflow: hidden` |
| 外框 | 1px 边框、10px 圆角、`0 20px 55px rgba(0,0,0,.24)` 阴影 |
| 遮罩 | `rgba(22,28,36,.40)`、1px 背景模糊；常规内边距 16px |
| 标题区 | 固定 52px、左右内边距 20px、底部分隔线；标题 16px、字重 650、行高 1.4 |
| 关闭按钮 | 28×28px、右上角、内置关闭图标、有可访问名称 |
| 正文 | `min-width/min-height: 0`、纵向滚动；内边距 `18px 20px 20px`、字段间距 17px |
| 标签/说明 | 标签 12px、字重 500、行高 1.5；说明 12px，错误使用现有错误色 |
| 文本输入 | 高度 36px、圆角 5px、内边距 `7px 10px`；聚焦有可见强调 |
| 只读路径 | `.ufs-create-location`、最小高度 36px、浅色面板、长路径可换行 |
| 底栏 | 固定 64px、左右内边距 20px、顶部分隔线、按钮右对齐 |
| 底部按钮 | 高度 34px、最小宽度 85px、圆角 5px、内边距 `6px 16px`、间距 9px |
| 窄屏 | ≤560px：遮罩内边距 10px，标题/底栏左右 15px，正文内边距 15px |

标题和操作区不随正文滚动，长路径、文件名、冲突列表不能把按钮推出可视区域；不设置固定整窗高度制造空白，不引入整窗横向滚动。

复制目标树沿用 225px 独立滚动区、32px 目录行和约 36px 行内编辑行。目标路径和“忽略/覆盖”使用正文与底栏之间的 `.ufs-copy-fixed-options`，仅目标选择视图显示，清单/进度视图隐藏。

### 4.2 颜色、图标和滚动

- 复用 `--ufs-bg`、`--ufs-panel`、`--ufs-text`、`--ufs-muted`、`--ufs-border`、`--ufs-hover`、`--ufs-accent` 等主题变量。主按钮使用强调色与白字，默认 Unraid 为橙色、DSM 为蓝色，不为新窗口另定品牌色。
- 取消/关闭使用中性样式，主要动作在最右侧。普通表单顺序为“取消 → 创建/重命名/开始复制”；运行视图按状态显示后台、停止、关闭等动作。
- 复用 `icon()` 的内置 SVG，不加载外部图标/字体。禁用态真正设置 `disabled` 并提供可见或可访问的原因，不能只降低透明度。
- 正文/目标树复用原生细滚动条和 `setupListScrollbars()`：6px、默认透明，悬停/滚动时显示，停止滚动约 1100ms 后移除活动态，仍悬停时保持显示。保留滚轮、触控板、滑块拖动；树悬停时不同时高亮外层滚动条。
- 不依赖 Unraid 全局控件样式。复制策略保留真实 radio 输入和自绘外圈/中心点，不能因视觉优化丢失键盘/选中语义。
- 非关键策略说明使用支持悬停和键盘聚焦的 Tooltip；阻止提交的原因、错误和待核实结果常驻可见。覆盖策略沿用已验收布局，不新增常驻警示条。
- 动效只表示真实活动状态，遵守 `prefers-reduced-motion`，减少动画时仍有状态文字。

## 5. 操作逻辑

### 5.1 关闭、取消和停止

| 状态/场景 | 关闭按钮、遮罩点击、Esc | 明确动作 |
| --- | --- | --- |
| 普通表单/复制目标选择，尚未提交 | 关闭，不产生写入 | “取消”含义相同 |
| 新建/重命名正在写入 | 禁止关闭；关闭/取消/提交禁用 | 等待结果，防止重复提交 |
| 复制行内新建正在编辑 | 第一次 Esc 取消编辑并恢复父窗口焦点，第二次退出父视图 | Enter/确认只创建目录，不开始复制 |
| 行内新建写入中或批量预检中 | 沿用忙碌限制，不退出导致状态丢失 | 禁止并发提交或切换出正在处理的编辑 |
| 复制清单子视图 | Esc 返回主视图，保留目标/策略/任务 | 使用既有“返回”动作 |
| 复制正在运行或已排队 | 收起到后台，保留任务/进度 | “后台运行”只收起；“取消排队”只移除未开始任务 |
| 单项复制运行中 | 不发送停止请求 | “取消复制”经归属检查和原生二次确认 |
| 批量复制运行中 | 收起与停止分别处理 | “停止”在原窗口展示选择；当前项结束后停止，或确认后尝试立即停止 |
| 复制完成/停止/待核实 | 用户可关闭，不定时自动消失 | 保留结果入口至手动关闭；关闭不代表核实/重试/清理目标 |
| 只读详情/诊断对话框 | 只结束查看 | 关闭不改变任务；清空日志单独确认 |

这是统一目标；恢复详情和诊断的当前缺口见第 8 节。Esc 按“行内编辑 → 子视图 → 当前层”处理并阻止冒泡，不得同时清空文件选择、导航或停止原生任务。

“取消排队”“停止复制”“关闭窗口”“后台运行”“跳过此项”在文案与实现上必须区分。Unraid 停止接口是全局操作，保留归属检查、并发风险和残留文件说明，不绑定通用关闭行为。

### 5.2 表单、状态和结果

- 默认新建名称“新建文件夹”并全选；重命名预填原名，文件选择不含扩展名部分；复制默认忽略同名项目。
- 打开时固定操作对象、源路径和目标上下文，后续选择/导航不能改变本次对象。Enter 经同一表单提交入口，搜索、树按钮和行内编辑不能误提交外层表单。
- 提交前校验并显示具体原因；提交中禁用重复提交及会改变计划的输入，按钮使用“创建中…”等状态。可修正失败保留输入/选择，不关闭后只给提示。
- 区分“尚未提交的检查失败”“已核验成功”“已提交但结果不确定”。不确定时停止成功动效、显示核实建议、锁定本窗口再次写入，不自动重试或推断成功。
- 新建/重命名核验成功后关闭、反馈并按既有逻辑更新目录；复制保留窗口与任务结果供查看，不恢复早期自动关闭。
- 预检冲突一次展示所有已发现冲突、数量、是否开始写入及下一步；长清单限高滚动。复制“忽略”跳过同名文件，“覆盖”允许替换同名文件，两者对同名文件夹均沿用合并，不描述成一律跳过/整体替换文件夹。
- 批量摘要保留前三项及“查看全部”；清单可搜索、返回不丢上下文，沿用最多同时渲染 500 项，不因数量多撑高窗口。
- 进度/速度/ETA 来自可靠原生事件。文件夹内部文件百分比不是文件夹总体百分比，按项目统计标明“非字节进度”；核验/项目切换清理旧指标，速度超过 5 秒无更新不沿用，无数据不虚构。
- 持久化恢复只恢复记录/只读监控，后续队列由用户确认启动；已提交/待核实项不能直接重发，人工“跳过”不等于成功。

## 6. 键盘与可访问性

以下约束适用于新增和修改的交互，现有不足不视为可复用惯例。

- 模态对话框提供 `role="dialog"`、`aria-modal="true"` 和准确名称；非模态面板/浮层不声明模态；菜单、树、进度保留对应语义。
- 打开即聚焦有效输入或可聚焦窗口，无需鼠标点击才能 Esc。关闭/收起恢复触发点，触发点移除则回文件列表，后台任务优先回任务按钮。
- 模态期间 Tab/Shift+Tab 在窗口内有合理顺序，不能落到背景操作。重绘、懒加载和进度更新不抢焦点、不丢输入/选区/滚动；切换视图和后台恢复后重新建立焦点。
- 纯图标按钮有可访问名称，输入与标签关联，按钮可键盘激活；保留 `:focus-visible`，不能为去掉鼠标焦点框取消键盘焦点提示。
- 状态使用 `role="status"` 或温和 live 区域，阻塞错误沿用 alert；高频进度不反复播报全文或抢焦点，状态不只依赖颜色/动画。
- 浮层/菜单的 Esc 和外部点击只关闭当前层；开关维护 `aria-expanded`。任务面板关闭不改变队列。

## 7. 写入和诊断边界

- 文件写入入口使用 `planFileOperation()` 和既有原生写入函数，文件访问限定 `/mnt/user`；保留真实路径/名称验证、CSRF、写入锁、原生活跃任务检查和结果核验，界面不能绕过。
- 打开、查看、关闭、重新打开后台窗口、进度更新不提交文件写入。取消未开始排队不调用全局停止；立即停止只有明确动作、归属检查和确认后才请求。
- 保留复制持久化检查点与所有权约束，存储失败/所有权丢失暂停调度，不降级重发。成功不能只看 HTTP 成功或目标存在。
- 诊断沿用本地保存和脱敏导出，不自动上传。清空日志不清空复制任务，日志失败不改变文件操作结果；不展示无关令牌、凭证或诊断敏感内容。

## 8. 当前差异与后续收敛

以下依据静态源码确认，尚未在本次修复。修改相关功能时按统一目标收敛并补回归，未涉及部分不做顺手改造。

| 当前差异 | 后续约束 |
| --- | --- |
| 诊断挂在 `document.body`，使用 860px 深色外框、独立按钮/滚动样式，没有固定 52px/64px 外框 | 双模式入口和日志阅读可保留全视口挂载/较宽正文；修改外框时对齐标题、控件、关闭及滚动规则。独立配色须说明诊断用途，不复制到普通操作窗口 |
| 恢复详情复用外框，但缺初始/恢复焦点、Esc/遮罩关闭、`aria-modal`、滚动活动绑定及完整关闭图标名称 | 涉及详情交互时补齐共用关闭、焦点、名称和滚动，不作为新窗口模板 |
| 创建/重命名有输入焦点，复制有窗口和恢复焦点；当前模态窗口无完整 Tab 约束，部分缺关闭后恢复 | 相关交互按第 6 节实现/测试，不声称当前已满足全套键盘规范 |
| 诊断仅检查自身是否打开，主操作互斥主要检查 `.ufs-dialog-overlay` | 新增/调整入口检查所有自定义模态层，避免诊断与操作叠加，不只提高 z-index |
| 任务中心有重复点击/关闭按钮，没有专用 Esc/外部点击关闭和完整焦点管理 | 按非模态面板规则完善，关闭不取消队列，不套操作遮罩 |
| 操作输入/复制策略部分装饰色固定橙色，诊断颜色独立于主题 | 改动相关控件时检查两主题并按变量收敛，不扩大硬编码颜色 |

## 9. 验收要求

变更说明列出适用项、验证结果和未验证项。不受影响的行为无需机械新增测试；行为改动补对应回归，不能只断言类名。
